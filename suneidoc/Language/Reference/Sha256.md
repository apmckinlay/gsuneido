### Sha256

``` suneido
(string) => string
() => instance
```

If called with a string it simply returns the 32 byte SHA256 hash of the string.

For example:

``` suneido
Sha256("hello world").ToHex()
    => "b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9"
```

To accumulate a hash incrementally, you can create an instance and update it. For example:

``` suneido
hash = Sha256()
hash.Update("hello ")
hash.Update("world")
hash.Value().ToHex()
    => "b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9"
```

**Note**: Once Value() has been called, you can no longer continue to Update the hash.
